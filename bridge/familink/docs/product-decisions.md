# Familink プロダクト決定ログ（ADR）

> プロダクトの方向・スコープに関わる決定はここに残す。実装中に「仕様を変えたい」と思ったら、勝手に変えずまずここに論点を書き、CPO/取締役会の判断を仰ぐ。

## テンプレート（コピーして 0001-タイトル.md 的に追記）
```
## [番号] タイトル
日付：
状況/背景：
選択肢：A / B / C
決定：（採用案と理由＝継続率・スコープ・工数・出口への影響で説明）
決定者：CPO / 取締役会 / 高橋
影響：roadmap や design-principles を更新したか
```

## 0001（例）
## 0001 MVPに体調管理を含めない
日付：2026-06-16
状況：早期公開を優先したい。健康データは審査・プライバシー要件が重い。
選択肢：A 含める / B v1.0は外す
決定：B。中核（カレンダー/タスク/共有/Hoku）の継続率を先に証明する。
決定者：CPO
影響：product-roadmap.md の「後回し」に記載済み。
