# 個別返信（提案）テンプレ

配信元（REOorGA等）への**個別返信**用。AIが案件×要員ごとに下書きし、
**代表（オーナー）が確認して初めて sales@ から手動送信**。AIは自動送信しない。
提案メールは5点だけ（`../../skills/ses-sales/references/playbook.md` 準拠）。

**送信元＝ITSセールス：`sales@its-tokyo.com`**（このアドレスからのみ提案を送る）
**宛先＝配信元の会社・担当者**（受信メールから抽出した**担当者のアドレスをそのままToに入れる**）。
**⚠️ REOorGA配信アドレスからは絶対に送信・返信しない**（From/Reply-Toに入れない）。
会社の直アドレスが取れず配信リストのアドレスしか無い場合は**送らず「要・宛先確認」**にする。詳細 `sources.md`。

## 相手先ごとにパーソナライズする（重要）

各配信メールから **会社名・担当者名・担当者アドレス** を抽出し、下書きに差し込む。
書き出しは必ず **「〔会社名〕 〔担当者名〕さま」**。To はその担当者のアドレス。

```
From: sales@its-tokyo.com
To:   〔ルートゼロ担当のアドレス（受信メールから）〕
件名：Re:〔元の件名〕／ご提案（ITS合同会社）
```

> 会社名・担当者名は受信メールの差出人／署名から取る。敬称は「さま」。
> 相手の社名が不明なら「ご担当者さま」でフォールバックし、**宛先アドレスは必ず担当者の実アドレス**にする。
> 名乗り・署名は `signature.md`（村山愛／営業部）を正本とする。メール末尾に署名ブロックを必ず添付。

## 送信前チェック（代表）

- [ ] **From が ITSセールスアドレスか**（REOorGAアドレスになっていないか＝最重要）
- [ ] **To が配信元担当のアドレスか**（REOorGA宛になっていないか）
- [ ] 両刀（NW×Sec両方）を満たす要員か
- [ ] 単価が枠内か（①72万／②97万以下で粗利¥8万確保）
- [ ] 商流制約OKか（多重NGでないか＝元請け直に載せられるか）
- [ ] 稼働開始が案件に合うか
- [ ] スキルシートに誇張・虚偽がないか（強調順の最適化のみ）
- [ ] 属性条件（外国籍不可等）は自動判断せず代表確認済みか
