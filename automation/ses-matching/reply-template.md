# 返信テンプレ（配信元への「案件ご紹介」）

配信で来た**要員**に対し、こちらの**案件（遊技機 情シスインフラPL＝サーバ×NW両刀）を提示**し、
**オンライン面談可能日・最新の並行状況**を尋ねる返信。ITSセールス `sales@its-tokyo.com` から、
配信元の担当者へ送る。**送信は必ず代表が手動**（AIは下書きまで）。

> この返信は **LLMで書かせず、決定論のテンプレ差し込み**で作る（毎回まったく同じ・ブレなし・無料）。
> 生成の実体は `run_ses_matching.py` の `finalize_draft()`。

## 差し込む変数（4つ）

| 変数 | 由来 | 省略時 |
|---|---|---|
| ①件名 | 要員配信の件名（`src_subject`）。`Re:○○_ITS村山` の○○。手入力可 | 案件名 |
| ②会社名 | 配信元の会社（`company`）。手入力可 | 〇〇株式会社 |
| ③担当者名 | 先方担当（`person`）。「様」は自動付与。手入力可 | ご担当者 |
| 要員名 | 本文「配信で頂きました○○様」（`engineer`）。手入力可 | ご紹介要員 |

- テンプレ本体：`reply-template.txt`（プレースホルダ `{件名}{会社名}{担当者名}{要員名}{案件本文}`）。
- **案件本文**は固定文で、案件定義 `案件_YYYYMMDD_〇〇.md` の `<!-- MAIL-BLOCK-START/END -->` から**そのまま挿入**。
  文面を直したいときは、テンプレ本体（言い回し）か MAIL-BLOCK（案件内容）を編集する→次回以降の全返信に反映。

## 生成のしかた（チャット駆動）

代表が「〔要員〕で返信作って」と言えばAIが `make_draft.py` を叩く。①②③は手入力で上書き可：

```bash
python make_draft.py --pick A.N \
  --subject "NW/セキュリティ A.N 8月〜" --company "ルートゼロ株式会社" --person "伝刀"
```

## 送信前チェック（代表）

- [ ] **From が ITSセールス**（`sales@its-tokyo.com`）／REOorGA受信アドレスになっていないか（＝最重要）
- [ ] **To が配信元担当のアドレス**か（REOorGA宛・配信リスト宛になっていないか）
- [ ] ①件名・②会社名・③担当者名・要員名が正しいか
- [ ] 案件本文（単価・勤務地・開始時期など）が最新か
- [ ] 要員が案件要件（両刀・単価枠・年齢・商流）に照らして出して良い相手か（採点＋代表判断）
