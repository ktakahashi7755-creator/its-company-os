# 個別返信（提案）テンプレ

配信元（REOorGA等）への**個別返信**用。AIが案件×要員ごとに下書きし、
**代表（オーナー）が確認して初めて sales@ から手動送信**。AIは自動送信しない。
提案メールは5点だけ（`../../skills/ses-sales/references/playbook.md` 準拠）。

**送信元＝ITSセールス：`sales@its-tokyo.com`**（このアドレスからのみ提案を送る）
**宛先＝配信元の担当者**（受信メールから抽出）。
**⚠️ REOorGA配信アドレスからは絶対に送信・返信しない**（From/Reply-Toに入れない）。詳細 `sources.md`。

## テンプレ（配信への返信）

```
From: sales@its-tokyo.com（ITSセールス）
To:   〔配信元担当のアドレス（受信メールから）〕
件名：Re: 〔元の件名〕／ご提案（ITS合同会社）

〔担当者名〕さま
お世話になります。ITS合同会社の高橋です。
ご配信の案件に対し、下記エンジニアをご提案します。

1. 誰を　：〔イニシャル〕・NW/セキュリティ両領域〔経験年数〕年
2. なぜ合うか：〔必須要件への適合を2行。両刀・設計構築運用・PL経験を具体で〕
3. 単価　：〔希望単価〕
4. 稼働可能日：〔開始日〕
5. スキルシート：添付のとおり

面談1回・弊社同席の前提でも問題ございません。
ご検討よろしくお願いいたします。
```

## 送信前チェック（代表）

- [ ] **From が ITSセールスアドレスか**（REOorGAアドレスになっていないか＝最重要）
- [ ] **To が配信元担当のアドレスか**（REOorGA宛になっていないか）
- [ ] 両刀（NW×Sec両方）を満たす要員か
- [ ] 単価が枠内か（①72万／②97万以下で粗利¥8万確保）
- [ ] 商流制約OKか（多重NGでないか＝元請け直に載せられるか）
- [ ] 稼働開始が案件に合うか
- [ ] スキルシートに誇張・虚偽がないか（強調順の最適化のみ）
- [ ] 属性条件（外国籍不可等）は自動判断せず代表確認済みか
