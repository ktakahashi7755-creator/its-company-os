## 1. BP初回アプローチ文面（テンプレ）
```
件名：エンジニアのご提案・案件連携のご相談（ITS合同会社）

ご担当者さま
ITS合同会社の高橋と申します。通信・IT領域でエンジニアのご提案と案件連携を行っております。
現在、[スキル例：React/インフラ/PM] のエンジニアが稼働可能です。
御社で要員ニーズや進行中の案件がございましたら、スキルシートをお送りします。
まずは情報交換だけでも歓迎です。
```
ポイント：売り込みすぎない。「情報交換」から入って継続接点を作る。

## 2. 協力会社への人材打診文面
```
[案件概要：スキル/単価/稼働/期間/形態] の案件があります。
ご対応可能なエンジニアはいらっしゃいますか。スキルシートいただければ即提案します。
```

## 3. 提案メールの型（5点だけ）
1. 誰を（氏名イニシャル・経験年数）
2. なぜ合うか（必須スキルへの適合を2行）
3. 単価
4. 稼働可能日
5. スキルシート添付

## 4. 単価交渉の勘所
- 先に相手の単価レンジを引き出す（こちらから安値を提示しない）。
- 粗利¥8万/月を死守ラインに。割るなら「長期更新前提」「次案件の優先」など条件で取り返す。
- 精算幅（下限/上限時間）と超過/控除単価を必ず合意。曖昧だと後でもめる。

## 5. よくある失敗と回避
- 入金サイト未確認 → 資金ショート。**契約前に必ず確認。**
- 多重商流NG案件に二次で提案 → 即見送り。商流制約を先に聞く。
- 更新月を放置 → 突然の離脱。1ヶ月前接触をルール化。
- 代表が長期常駐に入る → 営業停止。短期/スポットのみ。
