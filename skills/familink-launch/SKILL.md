# Familinkストア公開スキル

既存のWebアプリ（React/TS/Vite/Supabase/Tailwind）を**作り直さずCapacitorでネイティブ化**してiOS/Android両方に出すのが最短。React Native書き換えは不要。カメラ（OCR用）・プッシュ等のネイティブ機能も使える。

> 開発の設計原則は `../familink-dev/SKILL.md`。優先順位は `../../docs/roadmap.md`（Phase 2）。

## MVPは絞る（リテンション＝買収価値）
- v1.0：家族グループ作成・共有 ＋ カレンダー ＋ タスク ＋ Hoku（軽量）
- v1.1以降：OCR予定読み取り → 家計 → 写真
- **体調は後回し**（健康データは審査・プライバシー要件が重い）

## 費用（2026・要再確認）
- Apple Developer Program：年99ドル（法人299ドル）
- Google Play：登録時25ドルの一回のみ
- 公開後に有料化する場合の手数料：年100万ドル未満は15%（小規模事業者プログラム）

## タイムライン（夜・週末前提で約8〜12週）
1. 1〜2週：開発者アカウント（Appleと**Google組織アカウント**）・**D-U-N-S番号取得**（合同会社なので組織登録。個人だと12人・14日のクローズドテストが必要なので組織が有利）・プライバシーポリシー・アカウント削除機能の設計
2. 3〜6週：Capacitorラップ・アイコン/スプラッシュ/プッシュ・ストア素材（スクショ・説明）・TestFlight/クローズドテスト
3. 7〜8週：審査対応・限定公開（最初の数家族）
4. 9〜12週：リテンション改善 → OCR/家計追加 → 家族プラン課金

## 申請前チェック（審査落ち主因を潰す）
- [ ] プライバシーポリシーURL
- [ ] Appleプライバシーラベル / Googleデータセーフティ申告（家族データを正確に）
- [ ] **アプリ内アカウント削除**（Apple必須）
- [ ] メタデータ・スクショの完備（不備とポリシー欠如が定番の却下理由）
- [ ] 認証情報は本人入力（代行しない＝全業務共通ルール）

## 公開後
- まず継続率（毎週使う家族）を証明 → そのうえで月額課金。ARR＋継続率が出口の物語。
