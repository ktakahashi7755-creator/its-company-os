# AI経営会議スキル（毎朝）

会社OSの心臓。毎朝10分、AI役員会を開き、その日いちばん大事なことを決めてから一日を始める。

## 進め方

1. 代表が `../../templates/daily-meeting.md` の「朝の入力シート」を埋める（2分）。
2. このスキルに入力シートを渡す。
3. CEO補佐・COO・CFO・SES営業責任者の4視点を統合して議事録を出力する。

## 入力（朝のシート）
```
■日付：
■昨日の成果（数値・出来事）：
■昨日できなかったこと：
■今日の予定：
■現在のKPI：BP◯ / 提案◯ / 面談◯ / 成約◯ / 稼働◯名
■現在の月利益見込み：◯万円
■迷っている論点（あれば）：
```
状態の正本は `../../docs/kpi.md` と `../../data/`。入力に数値が無ければそこを参照する。

## 出力フォーマット（議事録）
```
1. 昨日の成果確認（達成度・評価）
2. 本日の優先順位TOP3（時間順・各1行）
3. 売上/利益確認（月利益目標との差分・着地見込み）
4. 課題（いま最大のボトルネック1つ）
5. 改善案（今日打てる具体策3つ）
```

## ルール
- 理想論禁止。**今日実行できることだけ。**
- 固定費を増やさない／代表の時間を営業と意思決定に集約、を常に反映。
- 優先順位は必ず「今月の月利益を増やすか」で並べる。
- 迷っている論点があれば CEO補佐視点で「やる/やらない/保留」を1行で出す。
- 議事録は `../../docs/decisions/` に残すほどの重要判断が出たら、記録を促す。

## 自動化（将来）
慣れたらGitHub ActionsやSupabaseの日次バッチで「KPI取得→議事録生成→Not/Slack通知」まで自動化できる。まずは手動で型を固めることを優先。

## 取締役会との関係
朝会は日次のスタンドアップ（今日の優先決め）。大きな判断は `../board-meeting/SKILL.md`（AI取締役会）で多視点にかける。
