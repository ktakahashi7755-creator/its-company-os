# 日次経費・交通費・残高 記録スキル

高橋が**移動中に話す/打つだけ**で、その日の経費・交通費・4つの残高を解析し、
**税理士向け（出納帳）**と**家族向け（交通費一覧＋残高・見やすいHTML/Markdown）**を毎回同じ形で更新する。

> 運用データは `../../finance/08_日次経費/`。記録の言い回し辞書は `../../finance/08_日次経費/記録ルール.md`。
> 関連：資金繰り→`../finance-cfo`、決算・経費仕分け→`../tax-compliance`。

## このスキルの役割（楽さが最優先）
高橋は**自然文を1回送るだけ**。整形・計算・転記・再生成はすべてこちらが行う。
例（こう話せばよい）：
- 「今日は蒲田。往復1,741円。昼食800円現金。PASMOに3,000円チャージ。手持ち現金12,000円、PASMO残2,500円、個人口座◯◯円、法人口座◯◯円。」
- 「分倍河原に2回行った分まとめて。あとコンビニ540円カード。」
- 「今日は移動なし。残高だけ：手持ち9,800、PASMO2,500、個人◯◯、法人◯◯。」

## 回答ルール（厳守）
入力を受けたら必ずこの順で返す：
1. **解析結果の確認**：日付／店舗・現場／交通費（往復・片道）／その他経費（科目・支払手段）／報告された4残高 を箇条書きで復唱。
2. **更新内容**：どのファイルに何行追記し、残高をどう計算したか（差額が出たら明示）。
3. **生成した提出物**：税理士向け・家族向け（MD/HTML）のパスと、家族向けはそのまま貼れる要約。
4. **不明点（あれば1〜3個だけ）**：金額・支払手段・往復片道など、確定できない項目。

禁止（`../../CLAUDE.md`のガードレール）：
- **資料・発話にない金額を確定・補完しない（不明は空欄＝「要確認」）。** 勝手に往復/片道や科目を断定しない。
- 税務判断・経費可否の断定をしない（最終判断は税理士へ、と必要時に添える）。
- 認証情報・口座番号など機微情報を本文に書かない（残高の数値のみ）。

## データ構造（単一ソース＋生成物）
```
finance/08_日次経費/
├── README.md                 運用ガイド（高橋が読む唯一の入口）
├── 記録ルール.md              言い回し辞書・店舗マスタ・科目・残高計算ルール
├── YYYY-MM/
│   ├── 明細.md               【単一ソース】全取引の元帳（手で編集するのはここ＋残高.md）
│   ├── 残高.md               【単一ソース】日次の4残高スナップショット
│   ├── 提出_税理士_YYYY-MM.md  生成物：出納帳（収入/支払/差引・店舗別交通費集計）
│   ├── 提出_家族_YYYY-MM.md    生成物：家族向け（交通費一覧＋残高）Markdown
│   └── 提出_家族_YYYY-MM.html  生成物：家族向け（スクショ用・見やすいHTML）
├── templates/                月次ファイルの雛形（新しい月はここからコピー）
└── _sample/                  出力イメージのサンプル（IMG_9099再現）
```
**手で書き換える/AIが追記するのは `明細.md` と `残高.md` の2つだけ。** 提出3ファイルは毎回これらから再生成する（=単一ソースの原則）。

## ワークフロー（入力1回ごと）
1. **対象月を特定** → `YYYY-MM/` が無ければ `templates/` からコピーして作成。
2. **明細.md に追記**：1取引=1行。交通費は店舗/現場名と「往復/片道」を必ず保持。支払手段（現金/PASMO/個人/法人）を入れる。発話に金額がなければ金額欄は空欄＋区分「要確認」。
3. **残高.md に追記/更新**：その日の `手持ち現金・PASMO・個人口座・法人口座` の報告値を1行で記録。報告が一部だけなら、報告された口座のみ更新（他は前日値を引き継ぎ、計算値と差があれば注記）。
4. **残高の整合チェック**（補助。断定しない）：
   - 手持ち現金 ＝ 前日 ＋ 現金収入 − 現金支払 −（PASMOチャージ額）
   - PASMO ＝ 前日 ＋ チャージ − PASMO利用（交通費）
   - 個人/法人口座 ＝ 前日 ± 入出金
   - **報告された実測残高があればそれを正**とし、計算値とズレたら「差額◯円・要確認」と注記（黙って上書きしない）。
5. **提出物を再生成**：
   - 税理士向け（`提出_税理士_*.md`）：日付順の出納帳（収入/支払/差引残高＝現金ベース）＋非現金（PASMO/口座）取引の一覧＋月の店舗別交通費集計。
   - 家族向け（`提出_家族_*.md` と `.html`）：**手書き帳簿そのままの「日次出納帳」スタイル**。口座ごと（①手持ち現金 ②PASMO ③個人口座 ④法人口座）にセクションを分け、各セクションを **月日｜摘要｜収入金額｜支払金額｜差引残高** の表で**毎日1行ずつ**並べる（チャージ・交通費・収入も1行）。差引残高は各口座の繰越から増減で連鎖計算。HTMLは罫線付き帳簿風（`templates/家族_日次帳簿.html` 準拠）。末尾に【月計】（交通費合計・稼働日数）を小さく添える。
6. **確認を返す**（回答ルールの順）。

## 家族向け＝日次出納帳スタイル（手書き帳簿の見た目）
家族はこの形が見やすい。**手書きの帳簿をそのまま清書したイメージ**で出す。
- 口座ごとにセクション：**①手持ち現金 ②PASMO ③個人口座 ④法人口座**。
- 各セクションの列：**月日｜摘要｜収入金額｜支払金額｜差引残高**。
- **毎日分を1行ずつ**（その日の動きが複数なら複数行）。チャージ・交通費・収入・引出も行にする。
- **差引残高**は各口座の繰越（前月末 or 開始残）から、収入＋／支払−で連鎖計算。報告された実測残高があればそれを正とし差異は注記。
- 摘要は手書きのまま（例「東久留米〜蒲田」「チャージ」「収入」）。
- 末尾に小さく【月計】：交通費合計・稼働日数（＝現場へ行った日数のユニーク数）。

> 店舗別の集計（店舗｜稼働日数｜交通費合計）は**税理士向け**に残す（家族向けの主役は日次帳簿）。`_sample/交通費一覧_サンプル.html` は旧スクショ形式の参考として保管。

### 家族向けの体裁ルール（厳守）
- **「?」「暫定」「確認待ち」「自動生成」「⚠️」等の印・注意書きは一切入れない。** 人が手で記帳した帳簿そのものに見せる。
- 不明な額は**空欄**にする（推測印を付けない・無理に埋めない）。
- 免責・解説・メモも家族向けには書かない（そうした注記は税理士向けと内部の `明細.md` 側にだけ持つ）。
- 数字はカンマ区切り、差引残高は前残から増減で連鎖。

## 月初・月末
- 月初：前月末の4残高を新しい月の「繰越」として `残高.md` の先頭に置く。
- 月末：その月の提出3ファイルを最終再生成し、`docs/kpi.md` の経費/交通費があれば連携（任意）。

## 新しい月の作り方
`templates/` の中身を `YYYY-MM/` にコピーし、ファイル名の `YYYY-MM` を置換、先頭に前月繰越残高を記入。あとは通常運用。
