# SES業務オペレーションスキル

SESは「契約・請求・資金繰り」を外すと、売上が立っても現金が回らない。ここを仕組みで固める。

> 契約・税務・インボイスの最終判断は弁護士・税理士に確認。AIは下書きと論点整理まで（`../../CLAUDE.md` ガードレール参照）。

## 1. 契約管理

必要なひな形3点（`../../templates/` 配下に整備）：
- 基本契約書（取引の枠組み）
- 個別契約書/注文書（案件ごとの単価・期間・精算条件）
- 秘密保持契約（NDA）

レビュー必須観点：
- 単価・精算幅（下限/上限時間）・超過/控除単価
- 契約期間と更新条件、中途解約の予告期間
- 支払サイト（締め日・支払日）
- 再委託・多重商流の可否
- 損害賠償・知財・反社条項

## 2. 請求・入金管理（月次）

```
締め日：     請求書発行日：     入金予定日：
クライアント別：請求額 / 入金確認(✓)
協力会社別：支払額 / 支払予定日
```
- **インボイス（適格請求書）対応**を確認（登録番号・税率・税額表記）。詳細は税理士へ。
- 入金確認は毎月チェックリスト化。未入金は早期に督促。

## 3. 資金繰り（最重要）

SESは **協力会社への支払が先 → クライアントからの入金が後** になりやすい。
- 毎月「支払予定 vs 入金予定」を並べ、ショート月を事前に検知（`../finance-cfo` と連携）。
- 入金サイトが長い案件を増やすときは、運転資金の余力を必ず確認。
- 危険信号：稼働増＝売上増だが現金は先に出ていく。**成長期ほど資金注意。**

## 4. 要員管理

- 稼働中エンジニア台帳：氏名 / 案件 / 単価 / 契約期間 / **更新月** / 連絡先。
- **更新月の1ヶ月前に必ず接触**（継続意思・条件確認）。空白期間＝粗利ゼロを防ぐ。
- 勤怠・精算：月次で稼働時間を集計し、精算幅と照合。超過/控除を正しく請求。

## 5. 外注化（10月目安）

月利益が出たら、まずこの事務を業務委託/AIへ移管：
- 請求書発行・入金確認
- スキルシート整形・面談日程調整
固定費にしない（月20〜30時間の時給制から）。代表の時間を営業と意思決定に集約する。
