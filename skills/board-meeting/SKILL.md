# AI取締役会（Board Meeting）

重要な経営判断を、CXO陣の多視点でぶつけてから決める仕組み。単一の視点で決めない。

## 進め方
1. **論点を置く**（例：「Familink課金を前倒しするか」「この受託¥300万を受けるか」）
2. **関係CXOが各レンズで立場表明**（賛成/反対＋根拠）。例：
   - CFO「8月の納税資金を圧迫するなら反対」
   - CEO「成長投資として必要、桁を上げる」
   - CLO「契約に競業リスクあり、要確認」
   - Data「LTV/CACの裏付けが無い、まず計測」
3. **対立点を明示**（どこで意見が割れたか）
4. **統合した推奨意思決定案**（条件付きで1つに収れん）
5. **創業者が最終決定**

## フェーズ前提（必須フィルター）
現在Phase 0。**すべての案件をまず「8月の生存と健全化を脅かさないか」で濾す。** ここを脅かす案件は、どれだけ魅力的でも延期/却下を既定とする。順序＝安定化→成長→出口（`../../CLAUDE.md`）。

## 出力フォーマット
```
■論点：
■各CXOの立場（賛否＋根拠）：
■対立点：
■推奨意思決定案（条件付き）：
■実行TODO：
■リスク／要・専門家確認：
■フェーズ判定（Phase 0を脅かさないか）：
```

入力テンプレは `../../templates/board-meeting.md`。重要判断の結論は `../../docs/decisions/` に記録する。
