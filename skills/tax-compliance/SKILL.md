# 税務・コンプライアンス管理スキル

ITSの足元（Phase 0）の中核。**税理士契約は解約済み**のため、AIが事故防止の整理と下書きを担う。**税理士・弁護士ではない。**

> 運用データは `../../finance/`。CFO指示書は `../../finance/CFO指示書.md`。資金繰りは `../finance-cfo`。

## 回答ルール（厳守）
必ずこの順で出す：①結論 ②現状整理 ③リスク ④優先順位 ⑤次の具体行動 ⑥必要なら文面（税務署・年金事務所等）。
禁止：根拠なく「問題ない」と言う／税務を断定する／**資料がない数字を確定・補完する（不明は空欄）**／法律判断をする。最終判断は専門家へ、と必ず添える。

## 最重要フェーズ
```
2024/07/17 設立 → 2025/06末 第1期決算 → 2026/06/30 第2期決算 → 2026/08末 申告・納税（予定）
```
8月末が動かせない期限。期限の正確日は決算確定日・通知で要確認。

## ワークフロー
1. **資料を集める**：銀行明細（全口座）・クレカ・請求書・領収書・契約書（`../../finance/03_銀行明細/` `../../finance/07_決算準備/`）
2. **仕分ける**：売上／法人経費／要確認／役員貸付金候補の4分類。判断できないものは"要確認"に置き費用にしない
3. **未払いを洗う**：税金（`../../finance/01_税金管理/納期限一覧.md`）・社保（`../../finance/02_社会保険/`）
4. **役員貸付金**：私的利用候補を抽出（`../../finance/04_役員貸付金チェック/`）
5. **決算→申告**：決算確定 → 申告書 → 納税資金確保 or 分納相談（最終は税理士確認）
6. **判断材料**：継続/休眠/整理の材料を1枚に（`../../finance/06_弁護士提出資料/`）

## 休眠の注意
休眠しても過去の税・社保債務・既発生の申告義務（特に第2期決算→8月申告）は原則消えない。確認先：税務署／都道府県税事務所／年金事務所。

## 戦略的論点（判断はしない・専門家へ）
Familink（価値ある資産）を、債務を抱えたITSに巻き込まない保有形態が望ましいか。債権者がいる状況の資産移動は否認等の法的リスクがあるため、弁護士・税理士に確認する論点として扱う。
