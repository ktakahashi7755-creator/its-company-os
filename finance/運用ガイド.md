# 運用ガイド（税務・経理・資金繰り・バックオフィス統合管理）

`CFO指示書.md` がAIの役割・禁止事項の正本。本ガイドは**日々の運用手順**と、外部の詳細プロンプト（税務・経理管理AI引き継ぎ）を**この `finance/` 構成に対応づけた索引**。別の `ITS-management/` ツリーは作らず、ここに集約する。

## 目的（最優先方針）
1. 差押え・督促・期限超過・申告漏れなど**緊急事故を防ぐ**
2. 未払い総額と支払期限を把握する
3. 法人／個人の資金混在を整理する
4. 決算・申告に必要な資料を揃える
5. 税理士・弁護士へ引き継げる状態を作る
6. 毎月継続できる管理フローを作る

## 回答の型（AIは毎回この順で出す）
1. 結論（最重要を一言）→ 2. 内容の整理（初心者向け）→ 3. 金額・期限・相手先（一覧）→ 4. 今やること（優先順位順）→ 5. そのまま使える文面（必要時）→ 6. 不足情報 → 7. 注意点（リスク）

## 事実／推測／要確認を必ず区別
- **事実**：資料・通帳・通知・契約書・申告書で確認できる
- **推測**：資料不足で可能性として考えられる
- **要確認**：税務署・都税・年金事務所・専門家への確認が必要
- 確度タグ：`確定 / 暫定 / 推定 / 未確認 / 争いあり / 専門家確認中`

## 資料が届いたら（毎回）
1. 日付・相手先・対象期間・金額・期限を確認 → 2. 既存台帳との重複/矛盾を確認 → 3. `13_ログ/document_intake_log.csv` に登録 → 4. 該当台帳・詳細mdを更新（旧値は残す）→ 5. 優先度を更新 → 6. 次の行動と不足情報を提示 → 7. `13_ログ/action_log.csv` に記録

## 毎月の締め（`templates/月次ルーティン.md`＋`資金繰り表.md`）
明細取得 → 売上/入金・支払/出金・領収書/カードの照合 → 証憑不足・私的利用候補・役員貸付/借入候補の抽出 → 未払い税/社保の更新 → 翌月納期限の確認 → 資金繰り更新 → 未解決事項の一覧 → ログ記録。

## 確認先の早見
- 税務署：法人税・消費税・源泉・国税の未払い/分納・申告期限・納税証明
- 都税/自治体：法人住民税・事業税・均等割・地方税の未払い/分納
- 年金事務所：健保・厚年・社保の未払い/分納・適用/資格
- 税理士：決算・税額計算・申告書・仕訳確定・役員貸付処理・消費税判定・期限後/修正申告
- 弁護士：破産・債務整理・差押え対応・契約違反・事業譲渡・代表者責任・債権者対応
- 司法書士：解散/清算人/役員変更/本店移転の登記
- 社労士：従業員の社保・資格得喪・給与計算・労働保険・退職手続き

## 休眠/解散/清算/破産（別概念・混同しない）
休眠しても法人は残り、**申告義務・均等割・過去の未払い税/社保は原則消えない。** 破産/債務整理は弁護士、解散/清算登記は司法書士、最終申告は税理士/税務署へ。判断材料は `06_弁護士提出資料/` に集約し、AIは判断しない。
