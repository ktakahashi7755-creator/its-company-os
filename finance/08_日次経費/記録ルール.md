# 記録ルール（言い回し辞書・店舗マスタ・残高計算）

AIが高橋の自然文を**ブレなく同じ形に変換する**ための辞書。新しい店舗・言い回しが出たらここに追記する。

---

## 1. 店舗マスタ（現場名と既定の往復交通費）
家族向け「交通費一覧」の店舗キー。**往復分交通費の既定値**を持つと、毎回金額を言わなくても済む（言われた実額が優先）。

| 店舗キー | 別名・最寄り等 | 往復分交通費（既定） | 備考 |
|---|---|---|---|
| 蒲田 |  | （要確認） | |
| 分倍河原 |  | （要確認） | |
| 武蔵小杉 |  | （要確認） | |
| 調布 |  | （要確認） | |
| 座間 |  | （要確認） | |
| 港南台 |  | （要確認） | |

> 既定値は**実際の精算額が分かってから**埋める（最初は要確認）。提供スクショの金額はあくまで過去の一例として `_sample/` に保管し、ここには確定値のみ入れる。
> 新しい現場が出たら行を追加。「いつもの蒲田」と言われたら既定の往復額を使い、違えば実額を優先＋注記。

## 2. 支払手段の言い回し → 区分
| 高橋の言い方 | 区分（記録値） | 影響する残高 |
|---|---|---|
| 現金 / キャッシュ / 財布から | 現金 | 手持ち −|
| PASMO / パスモ / IC / タッチ | PASMO | PASMO −（交通費） |
| チャージ / 入金（PASMOに） | PASMOチャージ | 手持ち −・PASMO ＋ |
| カード / クレカ / 個人カード | 個人カード | （口座は引落時。当面メモ） |
| 個人口座 / 個人の口座から | 個人口座 | 個人口座 − |
| 法人 / 会社 / 法人カード / 法人口座 | 法人 | 法人口座 − |
| ATM / 引き出し / 下ろした | 現金引出 | 個人/法人口座 −・手持ち ＋ |

支払手段が不明なら区分「要確認」。決め打ちしない。

---

## 3. 交通費の言い回し
- 「往復◯円」→ 往復＝そのまま交通費。
- 「片道◯円」→ 片道。**往復にするか確認**（自動で2倍にしない）。
- 「◯◯に行った」だけ → 店舗マスタの既定往復額があれば適用、無ければ金額を要確認。
- 「◯◯に2回」→ 同日2回なら稼働日数は1日、交通費は実態に応じて（往復2回分か確認）。

## 4. 勘定科目のあたり（税理士向けの目安／断定しない）
| 内容 | 科目の目安 |
|---|---|
| 電車・バス・PASMO利用 | 旅費交通費 |
| 昼食・飲食（単独） | （私的の可能性＝要確認。会議費/接待は相手・目的が要る） |
| コンビニ・文具 | 消耗品費 など（中身次第・要確認） |
| 通信・サブスク | 通信費 など |

> 科目は**最終的に税理士が確定**。AIは目安を付けるだけで、私的/事業の線引きは断定しない（役員貸付金候補は `../04_役員貸付金チェック/` と接続）。

## 5. 残高計算ルール（補助。実測値が常に優先）
```
手持ち現金(終) = 手持ち現金(前日) + 現金収入 − 現金支払 − PASMOチャージ額 + 現金引出額
PASMO(終)     = PASMO(前日) + チャージ額 − PASMO利用（交通費）
個人口座(終)   = 個人口座(前日) + 入金 − 出金 − 個人引出
法人口座(終)   = 法人口座(前日) + 入金 − 出金 − 法人引出
```
- 高橋が**実測残高を報告したらそれを正**とし、計算値とズレたら「差額◯円・要確認」と注記（黙って上書き禁止）。
- 報告が一部の口座だけなら、その口座だけ更新。残りは前日値を引き継ぐ（＝同値）。
- どの口座も前日値が無い（記録開始日）なら「繰越＝報告値」とし、不明なら空欄。

---

## 6. 日付の扱い
- 「今日」＝実行日。「昨日」「6/12」等は明示日付に正規化。
- 後から過去日を追記された場合は、その日付の行を挿入し、以降の差引残高を再計算（実測報告があればそれを基準に）。
