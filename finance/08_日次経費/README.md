# 08 日次経費・交通費・残高（税理士＆家族 提出用）

毎日の経費・交通費・4つの残高を、**移動中に話す/打つだけ**で記録し、
**税理士向け（出納帳）**と**家族向け（交通費一覧＋残高・見やすい形）**を毎回同じフォーマットで自動更新する。

> 動かす頭脳は `../../skills/daily-expense/SKILL.md`。言い回し辞書は `記録ルール.md`。

---

## いちばん大事なこと（運用は1ステップ）
高橋がやるのは**「その日の内容を1回送る」だけ**。整形・計算・転記・提出物の再生成は全部AIがやる。

### 送り方の例（このままで通じる）
- 「今日は蒲田。往復1,741円。昼食800円現金。PASMOに3,000円チャージ。手持ち12,000円、PASMO2,500円、個人◯◯、法人◯◯。」
- 「分倍河原に行った。往復844円。コンビニ540円カード。残高は手持ち9,800、PASMO2,500、あと口座は変わってない。」
- 「今日は移動なし。残高だけ：手持ち9,800、PASMO2,500、個人◯◯、法人◯◯。」
- 「昨日の蒲田、書き忘れ。往復1,741円だけ追加して。」

> 金額が分からない項目は**空けたまま送ってOK**。AIが「要確認」として残し、決め打ちで埋めない（ガードレール）。

## 何が記録され、何が出てくるか

| ファイル | 役割 | 誰が触る |
|---|---|---|
| `YYYY-MM/明細.md` | 全取引の元帳（単一ソース） | AIが追記（手修正も可） |
| `YYYY-MM/残高.md` | 日次の4残高（手持ち/PASMO/個人/法人） | AIが追記（手修正も可） |
| `YYYY-MM/提出_税理士_YYYY-MM.md` | **税理士向け**：出納帳（収入/支払/差引）＋店舗別交通費 | 自動生成（触らない） |
| `YYYY-MM/提出_家族_YYYY-MM.md` | **家族向け**：交通費一覧＋残高（Markdown） | 自動生成（触らない） |
| `YYYY-MM/提出_家族_YYYY-MM.html` | **家族向け**：スクショ用の見やすいHTML | 自動生成（触らない） |

**提出3ファイルは毎回 明細.md＋残高.md から作り直す。** だから真実は常に元帳側にある。

### 家族へのスクショ手順
`提出_家族_YYYY-MM.html` をブラウザで開く → スクショ → 家族へ共有。
（GitHub上では `.md` がそのまま表で見える。見やすさ重視のときはHTML。）

## 4つの残高の考え方
- **手持ち残高**：財布の現金。現金支払で減り、ATM出金やPASMOチャージは「現金→他へ」の移動。
- **PASMO口座残高**：チャージで増え、交通費（PASMO利用）で減る。
- **個人口座残高**：個人の銀行残高。
- **法人口座残高**：ITS法人口座の残高。

毎日「実測値」を送れば、それが正。AIは計算値とのズレがあれば**注記するだけ**（黙って上書きしない）。
一部の口座だけ報告した日は、報告した口座のみ更新し、残りは前日値を引き継ぐ。

---

## 家族向けの見方（日次出納帳スタイル）
家族には**手書き帳簿そのままの“毎日分”の見た目**で出す。口座ごとにセクションを分ける：

**② PASMO（例）**
| 月日 | 摘要 | 収入金額 | 支払金額 | 差引残高 |
|---|---|---:|---:|---:|
| 6/1 | チャージ | 2,000 |  | 3,560 |
| 6/1 | 東久留米〜蒲田 |  | 1,748 | 1,812 |

- セクション：①手持ち現金 ②PASMO ③個人口座 ④法人口座。
- 毎日分を1行ずつ。差引残高は繰越から増減で連鎖計算。
- 末尾に小さく【月計】（交通費合計・稼働日数）。

出力イメージは `2026-06/提出_家族_2026-06.html`、テンプレは `templates/家族_日次帳簿.html`。
（店舗別の集計は税理士向けに残す。旧スクショ形式は `_sample/交通費一覧_サンプル.html`）

---

## 新しい月になったら
`templates/` を `YYYY-MM/` にコピー → ファイル名の `YYYY-MM` を置換 → 先頭に前月末の4残高（繰越）を記入。
これもAIに「新しい月にして」と言えばやる。

## 注意（`../../CLAUDE.md` 準拠）
- AIは税理士ではない。経費可否・申告の最終判断は税理士へ。
- **資料・発話にない数字は埋めない（不明は空欄＝要確認）。**
- このリポジトリは**プライベート前提**（残高・経費が入るため）。口座番号やパスワードは書かない。
