# 消費税

## 管理表
| 項目 | 内容 |
|---|---|
| 税目 | 消費税・地方消費税 |
| 課税/免税区分 | **課税事業者**（インボイス登録済＝適格請求書発行事業者のため。確度：暫定＝本人説明。登録通知で確定へ） |
| 申告要否 | **必要**（第2期） |
| 金額 | （売上の預かり消費税が出たら記入） |
| 納期限 | 2026年8月末 予定（要確認） |
| 現在状態 | 課税確定・金額未確定 |
| 対応予定 | 2割特例の適用可否を確認 → 申告・納付 |

## 2割特例（重要・使えれば大幅減＆記帳が楽）
- インボイス登録により課税事業者になった小規模事業者は、**納付額＝預かった消費税 × 20%** で計算できる特例（2割特例）が使える場合がある。
- メリット：仕入・経費の消費税を1件ずつ集計しなくてよい → 記帳・申告が大幅に楽。納税額も圧縮。
- 申告書上で「2割特例を適用」を選択する形（事前届出は不要なのが一般的だが要確認）。
- 適用できるかは要件確認（基準期間の課税売上1000万以下・登録がなければ免税だった等）。

## 確認事項
- [ ] インボイス登録日・登録番号（登録通知書 or e-Taxで確認）
- [ ] 2割特例の適用可否（第2期に使えるか）
- [ ] 第2期の課税売上高（預かり消費税の元）
- [ ] 会計ソフトで消費税申告書まで自動生成できる設定になっているか

> 最終的な区分判定・特例適用は、迷えばスポットで税務署/専門家に確認。AIは断定しない。
