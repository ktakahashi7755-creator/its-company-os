# 自力申告ロードマップ（税理士なしで第2期を完結する道筋）

方針：**税理士に依頼せず、Claude Code を頭脳に、会計ソフトと e-Tax/eLTAX を手足にして、第2期（2026/6期）の決算・申告・納税を自社で完結する。**
更新日：2026/8/1 ／ 申告・納税期限：**2026/8/31（月）予定**（延長届の有無で変動＝要確認）

> 前提の正直な整理：税理士は**法律上の必須ではない**。合同会社が自分で申告するのは合法。ただし「Claude Code だけ」では申告は完結しない（後述の役割分担）。数字は資料が来てから確定し、勝手に補完しない。

---

## 0. Claude Code / 会計ソフト / あなた の役割分担

| 誰が | 何をやる |
|---|---|
| **Claude Code（頭脳）** | 明細の分類、仕訳ドラフト、試算表チェック、税額の概算、別表・決算書の各行の意味を説明、e-Tax/eLTAX の画面を手順化、文面作成、期限・リスク管理、入力値のサニティチェック |
| **会計ソフト（手足）** | 記帳→決算書→**法人税・消費税・地方税の申告書（別表）を自動生成**、e-Tax/eLTAX 形式で出力 |
| **あなた（承認・提出）** | 金額の最終確認、電子証明書/ID で **e-Tax・eLTAX から提出**、納税 |

**Claude Code が「できないこと」（正直な線引き）**
- あなたに代わって申告書を提出できない（電子証明書・認証はあなたのもの。ガードレール上も代行しない）
- 数字の正しさを保証できない／税務上の責任を負えない
- 別表を手計算で「提出できる精度」で作るのは誤りが出やすい → **会計ソフトの自動生成を使うのが安全**

→ 結論：**「Claude Code ＋ 会計ソフト ＋ e-Tax/eLTAX」= 税理士なしで完結できる現実的な最小構成。** 完全手計算（ソフトなし）も不可能ではないが、残り約1か月・初心者・ペナルティのリスクを考えると非推奨。

---

## 1. 全体の流れ（この順で進む）

```
① 記帳の材料を集める（全口座明細・クレカ・請求書・領収書・契約書）
② 会計ソフトに取り込み → 仕訳（Claude Code が4分類＆A〜Jで下書き）
③ 決算整理（減価償却・未payments未収・役員貸付金・前払等）
④ 決算書ができる（BS・PL・社員資本等変動・注記・勘定科目内訳・事業概況説明書）
⑤ 申告書が自動生成される（法人税=別表／消費税／地方税）
⑥ 税額を確認 → 納税資金の確保 or 分納相談
⑦ e-Tax（国税）・eLTAX（地方税）で提出
⑧ 納付（口座振替・ダイレクト納付・ペイジー等）
```

## 2. 提出するもの（第2期）

**国税（e-Tax）**
- 法人税申告書（別表：一／二／四／五(一)／五(二)／十五（交際費）／十六（減価償却）など、該当分）
- 地方法人税申告書
- 消費税申告書 ※**課税事業者の場合のみ**（→ 3章の分岐）
- 添付：決算書（BS・PL・社員資本等変動計算書・個別注記表）・勘定科目内訳明細書・法人事業概況説明書

**地方税（eLTAX）**
- 法人住民税（**均等割は赤字・休眠でも発生**。都税なら最低ライン ≒ 年7万円程度＝要確認）
- 法人事業税・特別法人事業税

## 3. 消費税の区分【確定：課税事業者＝申告が必要】

**インボイス（適格請求書発行事業者）登録済み**（本人確認・2026/8）＝ 第2期は**課税事業者**。消費税申告は**必要**。
→ **「2割特例」が使える可能性が高い**（納付＝預かった消費税×20%。仕入・経費の消費税を集計しなくてよく、記帳も申告も大幅に楽）。適用可否・登録番号は `../01_税金管理/消費税.md` で確認。
→ 会計ソフト側で「課税事業者・2割特例」を設定すれば、消費税申告書も自動生成される。

## 4. 会計ソフトの選択肢（別表を自動生成できるもの）

| ソフト | 向き |
|---|---|
| freee（会計＋申告） | 明細自動取込・初心者UI。法人申告まで一気通貫 |
| マネーフォワード クラウド（会計＋申告） | 同上。銀行連携が強い |
| 弥生（会計＋申告オプション） | 定番。サポート厚め |
| 全力法人税 ほか | 単純な会社なら低コスト。決算書は別途 |

> どれでも Claude Code が「取り込んだ仕訳のチェック」「別表の各行の意味」「e-Tax 手順」を伴走する。ソフトは1つに絞る。

## 5. 残り約1か月の逆算（2026/8/1 起点）

| 時期 | やること | 詰まると致命的 |
|---|---|---|
| 8/1–8/7 | 全資料を集め切る／会計ソフトを1つ契約／消費税区分を判定 | 資料欠けは全工程を止める |
| 8/8–8/18 | 記帳（明細取込→仕訳）→ 試算表を締める | 記帳量がボトルネック。ここが本番 |
| 8/19–8/24 | 決算整理→決算書確定→申告書自動生成→税額確認 | 税額が出て初めて納税資金の要否が分かる |
| 8/25–8/29 | 納税資金の確保 or 税務署/都税へ分納相談（`../templates/`） | 払えないなら早めに相談 |
| **8/31** | **e-Tax・eLTAX で提出＋納付** | 動かせない期限 |

## 6. 間に合わない/払えない場合（事故を最小化）

- **払えない**：申告は期限内に出す（無申告加算税を避ける）。納税は税務署・都税へ猶予/分納相談（`../templates/連絡文面_税務署_分納相談.md`）。
- **記帳が間に合わない**：それでも申告は必要。優先度＝均等割（少額でも必ず発生）→ 所得計算 → 消費税。
- **第1期が未申告なら**：第1期分も併せて片付ける必要があり作業量が倍。最優先で確認。

## 7. 進め方（Claude Code への回し方）
1. 明細を `../03_銀行明細/` に置く →「4分類＆A〜Jで仕訳ドラフトを作って」
2. 会計ソフトに入れた試算表を貼る →「勘定残高のサニティチェックと、決算整理の抜け漏れを指摘して」
3. ソフトが出した税額を貼る →「概算と桁が合うか、別表の主要行を説明して」
4. e-Tax/eLTAX の画面で迷ったら →「この画面で何を入れるか手順化して」
- すべて `../13_ログ/action_log.csv` に記録。数字は確度付きで台帳へ。

> このロードマップは段取りであり、申告内容・税額の確定ではない。判断に迷う論点（消費税区分・役員貸付金の認定利息・休眠可否等）は、必要に応じてスポットで専門家に確認する選択肢も残す（＝完全自力とスポット相談は両立できる）。
