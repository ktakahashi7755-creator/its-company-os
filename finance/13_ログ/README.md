# 13 ログ（作業・連絡・資料受領の記録）

重要な対応は必ずここへ記録する。「台帳だけ変えて証拠を残さない」を禁止する（`../運用ガイド.md` 参照）。

## 3つのログ

### action_log.csv（作業ログ）
何をしたか。台帳を更新した／資料を分類した／文面を作った、等。
- 列：日時, 管理ID, 対象, 実施内容, 実施者, 結果, 次の対応, 次回期限, 関連ファイル, 備考

### communication_log.csv（連絡ログ）
税務署・都税事務所・年金事務所・弁護士・税理士・取引先とのやり取り。
- 列：日時, 相手先, 部署, 担当者, 連絡方法, 問い合わせ内容, 回答内容, 合意内容, 次回連絡日, 証拠ファイル, 備考
- **電話の口頭回答だけで重要判断を確定しない。** 担当者名・日時・回答を記録し、書面/メールで再確認する。

### document_intake_log.csv（資料受領ログ）
受け取った資料（レシート・請求書・督促状・通知・明細・契約書 等）を1件ずつ登録。
- 列：受領日, ファイル名, 資料種別, 相手先, 対象期間, 金額, 状態, 確度, 保存場所, 関連管理ID, 備考
- ファイル名の推奨：`YYYY-MM-DD_相手先_資料種別_金額_状態`（金額不明時は `金額不明_未確認`）
  - 例：`2026-07-15_日本年金機構_督促状_350000円_未対応.pdf`

## 確度（全ログ共通）
`確定 / 暫定 / 推定 / 未確認 / 争いあり / 専門家確認中` のいずれか（定義は `../運用ガイド.md`）。
