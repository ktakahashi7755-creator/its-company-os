# 資金移動の分類ルール（法人口座・法人カード・個人立替）

明細の1行ごとに、まず下記A〜Jのどれかに置く。**個人利用と断定できないものは「個人利用」ではなく「役員貸付金候補（D）」または「要確認（J）」と表現する。**

## 分類（A〜J）
| 区分 | 内容 | 送り先 |
|---|---|---|
| A 会社の売上 | 取引先入金・サービス売上・事業譲渡代金 | 05_sales相当（`../05...`は無し→請求/入金で管理） |
| B 会社の経費 | 事業に必要で証憑・目的が確認できる支出 | 決算準備 |
| C 経費候補 | 事業関連の可能性はあるが証憑/説明が不足 | 要・証憑回収 |
| D 役員貸付金候補 | 生活費・私的支出・使途不明の現金出金 | `../04_役員貸付金チェック/`・`../台帳/役員貸付金候補.csv` |
| E 役員借入金候補 | 役員が会社経費を立替・役員→会社の入金 | 要・精算記録 |
| F 給与・役員報酬 | 支給根拠・金額・決定記録が確認できるもの | 給与台帳 |
| G 税金・社会保険 | 国税・地方税・社保・源泉所得税 | `../01_税金管理/`・`../02_社会保険/` |
| H 借入・返済 | 金融機関・役員・第三者の借入と返済 | 借入一覧 |
| I 振替 | 法人口座間の移動など損益にならないもの | ― |
| J 要確認 | 相手先・目的・証憑が不明 | 要確認リスト |

## 簡易4分類（毎月の仕分けはまずこれ、その後A〜Jへ寄せる）
1. 売上（=A）
2. 法人経費（=B。システム費・通信費・広告費・外注費 等）
3. 要確認（=C/J。内容不明出金・領収書なし）
4. 役員貸付金候補（=D。生活費出金・私的利用・説明不能なカード利用）→ `../台帳/役員貸付金候補.csv`

## 役員貸付金候補として抽出する例（断定しない）
個人の家賃/食費/私的な買い物/家族関係支出/個人口座への送金/使途不明の現金引出し/私的旅行/事業目的が確認できない高額決済。
ただし次は別処理の可能性：役員報酬・経費精算・役員借入の返済・社宅費用・出張旅費・立替精算。**出金だけを見て断定しない。**

## AIへの依頼例
「2026年6月の明細を4分類に仕分けして。判断できないものは"要確認"に置き、勝手に費用にしない。役員貸付金候補は理由も添えて `台帳/役員貸付金候補.csv` の形式で出して。」
