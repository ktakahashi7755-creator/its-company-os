# ITS_AI_経営管理（CFO補佐AI）

ITS合同会社の経理・税務・資金繰り・バックオフィスを、Claude Codeで自社管理するためのワークスペース。税理士契約解約後の管理体制をAI補助で整備する。

## 使い方
1. このフォルダをClaude Codeプロジェクトとして開く。`CLAUDE.md` が最初に読まれ、AIは「CFO補佐（税理士ではない）」として動く。
2. `03_銀行明細/` に明細を入れて毎月仕分けさせる。
3. 各管理表（税金・社保・役員貸付金）を埋めていく。**金額は資料確認後に記入。AIに勝手に補完させない。**
4. `templates/月次ルーティン.md` で毎月の3表（PL・資金繰り・リスク）を作る。

## 成長計画（its-keiei-os）との関係
別ワークスペース `its-keiei-os`（SES・AI受託・Familink・3年バイアウト）の**バックオフィス／CFO層**がここ。
順序：**まず足元の健全化（決算・未払い・整理）→ それが「売れる会社」の第一条件 → そのうえで成長と出口。** 2つは別プロジェクトとして並走させてもよいし、`its-keiei-os/finance/` として統合してもよい。

## 重要な注意
- AIは税理士・弁護士ではない。最終的な申告・納税・法的判断は専門家へ。
- 休眠しても過去の税・社保債務・申告義務は原則消えない（特に第2期決算→8月申告）。
- **Familink（価値ある資産）を、distressedな法人に巻き込まない形が望ましい。どこで保有すべきかは弁護士・税理士に確認する論点**（資産移動には法的リスクもあるため自己判断しない）。
