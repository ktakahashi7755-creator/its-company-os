# 台帳（マスター一覧）

未払い・期限・役員貸付金候補を**1か所**で管理するCSV台帳。各論点の詳細md（`../01_税金管理/` 等）は説明・確認事項、こちらは**横串の一覧**。数字は資料確認後に記入し、勝手に補完しない。

## ファイル
| ファイル | 用途 | 対応する詳細 |
|---|---|---|
| `未払い債務マスター.csv` | 未払い・督促・分納中の債務を全件一覧 | 01_税金管理・02_社会保険・取引先・借入 |
| `期限マスター.csv` | 申告・納付・その他の期限を全件一覧 | 01_税金管理/納期限一覧.md |
| `役員貸付金候補.csv` | 法人口座からの個人用途候補 | 04_役員貸付金チェック/ |

## 債務区分（未払い債務マスター）
国税 / 地方税 / 社会保険 / 給与 / 取引先 / 金融機関 / 役員 / その他

## 状態
未確認 / 未払い / 督促受領 / 催告受領 / 分納相談前 / 分納相談中 / 分納中 / 支払済み / 金額争いあり / 専門家確認中

## 優先度
| 優先度 | 目安 |
|---|---|
| **緊急** | 差押え予告・最終催告・期限直前・連絡放置 |
| **高** | 納期限超過・督促受領・分納不履行 |
| **中** | 近い将来に納期限・金額未確定 |
| **低** | 期限に余裕があり支払原資も確保済み |

## 確度（金額・情報の信頼度）
| 確度 | 意味 |
|---|---|
| 確定 | 公的通知・申告書・納付書・銀行明細・契約書で確認済み |
| 暫定 | 本人説明・部分資料で仮登録 |
| 推定 | 資料不足のため計算・推測 |
| 未確認 | 存在は認識、内容/金額/期限が未確認 |
| 争いあり | 相手方と認識が不一致 |
| 専門家確認中 | 税理士・弁護士・行政へ確認中 |

## 更新ルール
- 過去の数字を上書きする時は変更前の値を残す（備考に旧値＋更新日）。
- 台帳を変えたら `../13_ログ/action_log.csv` に記録する。
- 期限マスターの日付（2026/8/31 予定 等）は決算確定日・通知書で要確認。**確定ではない。**
