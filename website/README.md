## 公開手順（5分・無料）

いずれか1つ。おすすめは1。

1. **Netlify Drop**：https://app.netlify.com/drop に `index.html` をドラッグ&ドロップ → 即公開。独自ドメインは後から設定可。
2. **GitHub Pages**：このフォルダを `its-website` リポジトリに分離 → Settings > Pages で公開。
3. **Vercel**：リポジトリ連携で自動デプロイ。
