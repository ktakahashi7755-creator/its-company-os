# 0002 — Web制作・簡易受託をPhase 0中に小さく開始する

## 日付
2026-07-08

## 状況 / 背景
- 高橋の指示：「ホームページ制作、システム受託開発などまずは簡易的でも良いので仕事を取りたい」。
- 一方、既存方針（CLAUDE.md／ai-jutakuスキル）では受託は「2026年は種まきのみ」。Phase 0（8月の決算・申告）が最優先。
- 会社には現金が必要であり、固定費ゼロ・前金・小型案件に限定すれば決算準備と両立可能。

## 選択肢
- A：既存方針どおり8月まで受託営業をしない
- B：制限付きで今すぐ開始（固定費ゼロ／前金50%＋仮払い／Claude Codeで作り切れる案件のみ／営業30分/日・制作は夜週末／決算作業と衝突したら受託を止める）
- C：全面的に受託営業へシフト

## 決定
**B を採用。** 理由：
- まず利益（原則2）：入口商品は粗利率が高く、固定費を1円も増やさない
- 代表の時間（原則3）：Claude Codeが制作の大半を担い、高橋は営業・確認のみ
- 出口（原則6）：納品実績と法人口座への入金実績は会社の信用資産になる
- Cを取らない理由：8月の申告は動かせない期限であり、Phase 0を割ってまで加速しない

## 想定リスクと撤退条件
- リスク：決算準備の遅延／低単価案件のスコープクリープ／プロバイド契約との競業懸念
- 対応：受注ルール（`docs/web-jutaku-strategy.md` §3）を厳守。プロバイド人脈チャネルは契約条項確認まで凍結
- 撤退条件：決算作業が予定より遅れ始めたら新規受注を停止。90日で成約0件なら取締役会で再設計
