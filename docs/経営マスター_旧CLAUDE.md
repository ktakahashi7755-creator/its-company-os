## 0. 現在地（正直な前提）

ITS合同会社は2つの顔を同時に持っている。

- **足元**：第2期決算（2026/6/30）と8月末の申告・納税が目前。税理士契約は解約済み。未払い税金・社会保険の可能性、役員貸付金の整理、休眠/継続/整理の判断が未決。
- **未来**：SESをキャッシュ核に、Familinkを売り物として育て、3年でバイアウトを狙う。

**この2つは矛盾しない。足元の健全化は成長の"脱線"ではなく、買収（出口）の"ステップ1"。** 未払い・混在口座・税理士不在の会社は売れないし伸びない。だから順序は固定：

> **① 安定化（足元を健全に） → ② 成長（SES＋Familink） → ③ 出口（バイアウト）**

迷ったら順序に戻る。①が割れている間は②③を全開にしない。

## 1. 会社の構造（誰が何か）

- **ITS合同会社**：高橋の自社。SES＝キャッシュ核、Familink＝売り物。**これが出口（売却）の対象。** 設立2024/7/17、決算6月、第2期。
- **プロバイド株式会社**：高橋は業務委託＋通信事業部の部長として関与。月¥70万の収入源。**売却対象ではない**が、(a)生活を支える燃料、(b)「通信会社の事業部長」という、Familink戦略売却でキャリア系買い手につながる人脈資産。
- 注意：プロバイド（SES・通信）とITSのSESは競業・利益相反になり得る。業務委託契約の競業/秘密保持条項を確認し、衝突でなく「ITSがプロバイドに供給/棲み分け」の形にする（`finance/05_契約書/`）。

## 2. 経営の原則（全判断の前提）

1. **まず安定化。** ①が終わるまで②③は最小限。8月の申告・納税は動かせない期限。
2. **まず利益、固定費を増やさない。** 雇用は最後。増員は外注・業務委託から。
3. **代表の時間を"作業"に溶かさない。** SESもイベントも「自分が動く」でなく「人を立てて粗利を取る（オーガナイザー/ブローカー型）」。
4. **¥80万突破が解放スイッチ。** 事業が月¥80万+を生めば、¥70万で今の収入を置換＋¥10万が利益。プロバイド事業部を"人に回す"形にして、自分の日中を空けるのが最初の山。
5. **AIを組織として使う。** 経営判断・営業・進捗・採用・開発・経理をAIに分担。高橋は営業と最終意思決定に集中。
6. **5億の出口はFamilinkのARRが作る。** SESは現金と信用、AI受託は高粗利の実績、Familinkは倍率。掛け算で5億。

## 4. フェーズ（時間設計）

- **Phase 0：安定化（〜2026/8）**…決算・申告・未払い把握。Familinkは夜に継続。SESは線引きと種まきのみ。
- **Phase 1：解放（〜+6ヶ月）**…プロバイド事業部を人に回し、日中を空ける。¥80万突破。
- **Phase 2：加速（〜18ヶ月）**…空いた日中でITS SES拡大＋選別受託。Familinkストア公開→リテンション→課金。
- **Phase 3：出口（2〜3年目）**…Familinkのトラクション/ARR＋会社の体裁を整え、部長人脈経由で戦略的バイアウト。

詳細は `docs/action-plan.md`（何を）、`docs/roadmap.md`（いつ）、`docs/exit-plan.md`（出口）。

## 6. ガードレール（厳守）

- AIは税理士・弁護士ではない。申告・納税・法的判断（休眠/整理/破産・契約有効性）の最終決定は専門家へ。
- **資料がない金額を確定・補完しない（不明は空欄）。** 根拠なく「問題ない」と言わない。
- 顧客が入力すべき認証情報（パスワード・認証コード）を会社側が代行しない（全業務・Familink共通）。
- 固定費を増やす提案には「何ヶ月で粗利回収できるか」を必ず添える。回収3ヶ月超 or 不明は原則保留。
- **Familink（価値ある資産）を、債務を抱えたITSに巻き込まない形が望ましい。どこで保有すべきかは弁護士・税理士に確認する論点**（債権者がいる状況の資産移動には否認等の法的リスク。自己判断しない）。
- 財務・売上予測は「検証すべき計画値」であり保証ではない。
