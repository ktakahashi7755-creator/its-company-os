# 営業自動化戦略 — フォームアプローチ×テレアポ温存モデル

作成日：2026-07-08
親戦略：`docs/web-jutaku-strategy.md`（商品・価格・受注ルールはそちらが正本）

---

## 0. 設計思想：「自動化がアポを作り、電話が決める」

高橋の強み＝テレアポ（クロージング力）。弱点＝時間がない。
だから**人間の時間を使う場所を「返信が来た後」だけに絞る**。

```
【自動】リスト生成 → 【自動】サイト診断・文面生成 → 【半自動】フォーム送信（1件10秒の確認クリック）
→ 返信（ここまで人間の時間ほぼゼロ）
→ 【人間】返信者に即・電話 ←テレアポ力を投入する唯一の場所。温かいリードだから刺さる
→ 見積（テンプレ）→ 前金 → 制作（Claude Code）→ 納品
```

コールドテレアポは1アポに数十件の架電が要るが、**フォーム返信者への折り返し電話は「相手が興味を示した後」なので数分の1の労力で商談化する**。得意技を最も高打率の場面に温存する。

## 1. ターゲット設計（誰に送るか）

「HPに課題があることが外から見える中小事業者」に絞る。診断スクリプトが機械的に見つけられるシグナル：

| シグナル | 意味 | 刺さる提案 |
|---|---|---|
| SSLなし（http のみ） | 「保護されていない通信」と警告が出ている | 危機訴求＋リニューアル（Bプラン） |
| スマホ非対応（viewport なし） | 客の7割が見るスマホで崩れている | リニューアル（A/Bプラン） |
| コピーライト年が古い（3年以上前） | 更新が止まっている＝担当者不在 | リニューアル＋保守月額 |
| サイト自体がない（SNS/食べログのみ） | 検索で公式情報が出ない | 新規制作（Aプラン） |

**業種の優先順**（単価と決裁の速さで選定）：
1. 士業（税理士・行政書士・社労士）— HPが信用に直結、決裁者本人
2. 工務店・リフォーム・造園などの職人系 — 案件単価が高くHP投資意欲あり
3. 治療院・整体・クリニック — 予約システム（Cプラン）への発展性
4. 地域の製造業・卸 — 採用目的のHP需要
5. 飲食・美容 — 数は多いが低予算。Aプラン即決狙いのみ

リストの作り方：Googleマップ・業種別ポータル（税理士ドットコム等）・商工会議所会員名簿など**公開情報**から「社名・URL・問い合わせフォームURL」を収集。**Claude Codeセッションで「◯◯市の工務店リスト20件作って」と指示すれば毎回私が作る。**

## 2. 実行の仕組み（`automation/form-sales/`に構築済み）

### ステップ1：リスト生成【自動】
`prospects.csv` に「社名, URL, 業種」を貯める（週50〜100件）。

### ステップ2：診断＋文面生成【自動】
```
node automation/form-sales/check_prospects.mjs automation/form-sales/prospects.csv
```
各サイトを巡回し、SSL/スマホ対応/コピーライト年/「営業お断り」表記を自動判定 →
**優先度スコア順に並べ、1社ごとに「相手のサイトの具体的な指摘」を入れた送信文を自動生成**して `output/` に出力する。

### ステップ3：フォーム送信【半自動・1件約60秒】
生成された文面をコピーして相手のフォームに貼り、送信。**1日20件・約30分。**
- 完全無人のフォーム自動送信ボットは**使わない**（下記ガードレール）。
- 送信したら `sent.csv` に記録（スクリプトが重複送信を防止）。

### ステップ4：返信対応【人間＝高橋】
- 返信が来たら**24時間以内に電話**（メール返信より電話。ここがテレアポ力の出番）
- 電話の場でヒアリング（`templates/hearing-web.md`の項目を口頭で）→ 当日中に見積送付
- 全件 `data/pipeline.md` に記録

## 3. ガードレール（法務・ブランド・厳守）

1. **「営業お断り」表記のあるフォームには送らない。** スクリプトが検知して除外する（検知漏れもあるので送信前に一瞥する）
2. **完全無人の一斉自動送信はしない。** 送信は必ず人の確認を挟む。理由：(a)誤送信・文面事故がブランドを毀損する、(b)大量機械送信は先方サーバーへの迷惑行為・業務妨害と受け取られるリスク、(c)フォーム営業への法規制・世論は変わりうる
3. **送信上限：1日20件・週100件。** 量より文面の質（相手サイトへの具体的言及）で返信率を取る
4. Eメール直接送信のコールドDMはしない（特定電子メール法のオプトイン原則。フォーム経由に限定する）
5. 「二度と連絡しないでほしい」と言われた相手は `do-not-contact.csv` に記録し永久除外
6. 文面に虚偽を書かない（「実績多数」等の盛りは禁止。実績が付くまでは「AI開発体制による低価格・短納期」だけで訴求する）
7. 有料のフォーム営業代行ツール（月額数万円）は**実績3件＋返信率の実測が出るまで保留**（固定費原則）

## 4. KPI（週次・`data/pipeline.md`に記録）

| 指標 | 目標 | 備考 |
|---|---|---|
| リスト追加 | 50〜100件/週 | Claude Codeで生成 |
| フォーム送信 | 100件/週（20件/日） | 半自動 |
| 返信率 | 1〜3% → 週1〜3件 | 下回ったら文面のABテスト |
| 返信→商談化（電話） | 50%以上 | テレアポ力でここを最大化 |
| 成約 | 月2件 | 親戦略のKPIと共通 |

**試算**：週100件送信 × 返信2% × 電話商談化50% × 成約50% ≒ **月2件成約**。
Aプラン¥30,000〜Bプラン¥100,000で**月¥6万〜20万の粗利**（原価ほぼゼロ）＋保守月額の積み上げ。

## 5. 「お金稼ぎの自動化」の育て方（段階設計）

自動化は一気にやらず、**成果が出た工程から順に機械に渡す**：

- **今（v1）**：リスト＝AI生成／診断・文面＝スクリプト／送信＝人（10秒/件）／クロージング＝電話
- **返信率が実証できたら（v2）**：クラウドソーシング応募文の毎朝自動下書き（私が毎セッション生成）、返信メールの下書き自動化、見積書の自動生成
- **月商が立ったら（v3）**：送信作業ごと外注（1件数十円で発注可能な作業に落ちている）or 有料ツール導入を粗利から回収計算のうえ判断
- **その先**：この「診断→文面→送信」の仕組み自体が商品になる（他社への営業DX支援＝Cプラン案件）

> 注意：Phase 0の縛りは生きている。この運用は1日30〜40分に収まる設計で、**8月の決算作業と衝突したら送信を止める**。
