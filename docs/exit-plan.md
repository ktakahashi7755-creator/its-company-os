# 出口計画（3年バイアウト）

## 何を売るか
ITS＋Familink。プロバイドは売らない（業務委託先・人脈資産）。

## 誰が買うか
財務投資家でなく**戦略的買い手**が本命：通信キャリア・家族サービス・保険・教育・IT受託のロールアップ。
**高橋がプロバイドの通信事業部長＝キャリア系買い手への最短の導線。** これが最大の武器。

## 2本立て
- 本命（高倍率）：Familinkを「実利用家族数＋早期ARR＋継続率」のある資産に → 戦略的買収。
- 保険（フロア）：会社まるごと（SES帳簿＋受託実績＋Familink＋"AIで自動運転する会社"の仕組み）売却。2〜3億規模。

## 買われる準備（2年目から開始。3年目では遅い）
- [ ] 帳簿・財務をデューデリ対応に（＝Phase 0の延長線）
- [ ] IP所有の明確化（Familinkコード・Claude Code自動化の仕組み）
- [ ] データ/プライバシー対応（家族アプリは監査で必ず見られる）
- [ ] 継続収益（ARR）と低い創業者依存。"AI経営OSで回る"こと自体が売り
- [ ] 合同会社→株式会社への変更を検討（買い手はKKを好む。税理士/弁護士へ）
- [ ] **Familinkの保有形態**を専門家と確認（distressedなITSに巻き込まれない形）

## 正直な注記
3年で5億はブートストラップの家族アプリとしては強気。届くのは戦略的買い手が戦略価値を払うルート。だから早期から買い手候補との非公式な関係づくりが効く。
