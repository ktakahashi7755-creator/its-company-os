# P8：採用・組織化

> 作成日：2026/7/3　ステータス：暫定確定
> 原則（CLAUDE.md・business-plan準拠）：**人を抱えない。外注 → 業務委託 → 雇用の順。** 雇用は「人件費を3ヶ月以内に粗利回収できる」場合のみ。AIで代替できる仕事に人を付けない。

---

## 1. 組織図（現在 → 6ヶ月 → 24ヶ月）

### 現在（2026/7）
```
高橋（代表）＝営業・決断・人間関係
└── AI組織（skills/）＝経理補助・営業事務・開発・進捗・分析
└── スポット外注：税理士（決算・申告）※最優先の「採用」はこれ
```

### 6ヶ月後（2027/1・月粗利¥100万水準）
```
高橋 ＝ 営業・決断
├── AI組織（P7の分担で拡張）
├── 税理士（顧問化を検討：月次の正確さ＝出口の帳簿づくり）
├── 業務委託：プロバイド事業部の実務を回す人（※これはプロバイド側の座組。ITSの固定費にしない）
└── 協力会社ネットワーク（SES供給元5社+）
```

### 24ヶ月後（2028・月粗利¥500万水準）
```
高橋 ＝ 経営・大口営業・出口準備
├── SES営業サポート（業務委託1名：候補出し・日程調整・書類）
├── 制作/開発パートナー（案件単位の外注2〜3名：デザイン・実装）
├── AI組織（顧客対応の一次回答まで拡張）
└── 士業（税理士顧問・スポット弁護士）
```

## 2. 「人に頼む」判断基準

| 条件 | 判断 |
|---|---|
| AIで80%以上こなせる | 頼まない（P7で自動化） |
| 単発・変動的 | 案件粗利の30%以内で外注 |
| 毎月発生・型が決まった | 業務委託（月額上限を先に決める） |
| 会社の中核・秘匿性が高い | 高橋が持つ（当面、雇用しない） |

**最初の3つの発注（この順で）**
1. **税理士（スポット→顧問）**：7月中。決算・申告は外注が前提（ガードレール）。
2. デザイン外注（単発）：L3案件でデザイン要件が重い場合のみ、案件ごと。
3. SES営業サポート（業務委託）：稼働5名を超えて事務が営業時間を侵食し始めたら。目安月¥5〜10万で、粗利増分から3ヶ月回収できる時のみ。

## 3. マニュアル（作る順序＝人に渡す順序）

マニュアルは「人を入れる直前」に、実際の作業ログから作る（先回りで書かない）。ただし以下は今から記録を残す：

| マニュアル | 元になる記録 | 作成時期 |
|---|---|---|
| SES提案の流れ（案件受領→シート整形→提出→面談調整） | `skills/ses-sales`＋実案件ログ | 稼働3名到達時 |
| 月次経理ルーティン | `finance/templates/月次ルーティン.md`（既存） | 済（運用で磨く） |
| 診断→提案→納品の型（L2/L3） | P5テンプレ＋初案件の実ログ | 初納品後 |
| プロバイド事業部の業務手順 | Phase 1「人に回す化」の棚卸し | 2026/9〜 |

## 4. プロバイド「人に回す化」（Phase 1の中核・再掲）

これは採用でなく**移管**。(1) 事業部業務を棚卸し→(2) 自分でなくてよい作業を特定→(3) プロバイド側の座組で人を立てる（部長の権限で。取り決めは要確認）→(4)「自分の手作業由来の収入割合」を毎月下げる。ITSの組織図には載せない＝ITSの固定費にしない。

## 5. セルフレビュー
