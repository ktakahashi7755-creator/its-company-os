> ITS合同会社の成長戦略を P1〜P9 の9工程で設計・実行するプロジェクトの正本。
> 開始日：2026/7/3　オーナー：高橋（最終意思決定）／推進：AI（共同CEOモード）

---

## 1. 位置づけ（最初に読む）

- 本プロジェクトは `CLAUDE.md`（統合経営OS）の**配下**にある。矛盾したらCLAUDE.mdが勝つ。
- **用語の区別**：会社の経営フェーズは「Phase 0〜3」（安定化→解放→加速→出口）。本プロジェクトの作業工程は「**P1〜P9**」と表記する。混同しない。
- 現在の経営フェーズは **Phase 0（安定化、〜2026/8末）**。本プロジェクトのすべての施策は「**8月の申告・納税と決算作業を脅かさないか**」で濾してから採用する。

## 2. 目的

最短でキャッシュを作り、利益を生みながら会社を大きくする。
目標（高橋提示・検証すべき計画値）：3ヶ月で月次利益¥100万 → 6ヶ月¥300万 → 12ヶ月¥500万 → 3年で売上3〜5億円・営業利益20%+。
※既存正本（`docs/kpi.md`）の目標との乖離は P1 で分析済み。**目標の確定は P2 で高橋が承認する。**

## 4. 最重要ルール（高橋指定＋CLAUDE.mdガードレール）

1. 利益率・キャッシュフロー・実現可能性を最優先。売上でなく利益。
2. 「作ること」より「売ること」。
3. 高橋一人でも実行可能な計画から開始。AI前提の少人数経営。
4. 施策は必ず3分類：**今すぐキャッシュ化／90日以内に利益化／1〜3年でスケール**。
5. 固定費を増やす提案には粗利回収月数を必ず添える（3ヶ月超 or 不明は保留）。
6. **資料がない金額を確定・補完しない（不明は空欄・要確認）。**
7. Phase 0の間、成長施策は「決算作業の時間を奪わない・固定費を増やさない・納税資金に手を付けない」の3条件を満たすものだけ実行する。
