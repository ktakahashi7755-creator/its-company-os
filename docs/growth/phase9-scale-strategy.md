# P9：スケール戦略 — 3年で売上3〜5億・出口接続

> 作成日：2026/7/3　ステータス：暫定確定（`docs/exit-plan.md` `docs/financial-model.md` と整合）
> 3年の絵は「検証すべき計画値」。毎年の実績で必ず引き直す。

## 1. スケールの構造（何が伸びて3億になるか）

売上を伸ばす3つのエンジンと、それぞれの「一人経営のままの上限」：

| エンジン | スケール様式 | 上限を外す仕掛け |
|---|---|---|
| L1 SES | 稼働数 × 粗利/名。線形 | ブローカー網の深さ（BP1社で複数案件）＋営業事務のAI/委託化 → 20名規模まで一人で回る設計 |
| L2〜L5 商品・受託 | 件数 × 単価。高橋の納品時間が天井 | 型化（P5テンプレ→P8マニュアル）＋実装の外注化＋**単価を上げる**（安件数を追わない） |
| F Familink | ARR。非線形（人時間に比例しない） | リテンション→課金→倍率。**3億→5億の差分はほぼここ** |

**戦略の核：SESと受託は「評価ベース（EBITDA）」を作り、Famiinkは「倍率」を作る。** 2つは掛け算（financial-model.mdの5億ブリッジ）。

## 2. 年次マイルストーン（計画値）

| 年度 | 売上目標 | 状態目標 | 出口準備 |
|---|---|---|---|
| **2026下期** | 生存＋粗利月¥30〜50万 | Phase 0完了・商品3本・SES再稼働 | 帳簿を綺麗に（第3期から月次を正確に） |
| **2027** | ¥1.2億（SES ¥1.0億＋受託¥2,000万） | 日中解放・SES 10名前後・受託の型完成 | IP・契約・データの整理開始／Familink保有形態を士業と確定 |
| **2028** | ¥2.2〜2.5億 | SES 15名＋受託¥6,000万＋Familink売上¥1,000万 | KK化検討・買い手候補と非公式接点（部長人脈） |
| **2029** | ¥2.9億±・営利20% | Familink ARR ¥4,000万 | 戦略的売却の実行判断（本命）／会社売却（保険） |

## 3. スケール期の投資判断ルール

1. 投資（外注増・ツール・広告）は**粗利の後追い**でのみ行う。先行投資はFamilinkの夜時間だけ。
2. 広告費は「1受注あたり獲得コスト < 初回粗利の50%」が実測できるまで月¥5万を上限に実験。
3. 単価を上げる方が件数を増やすより先。値上げは事例が2件貯まるごとに検討。
4. 大型受託（¥300万+）は資金ショート試算（支払先行）を通ってから受注。

## 4. リスクと撤退基準

| シナリオ | 兆候 | 打ち手 |
|---|---|---|
| SESが伸びない | 2027前半で稼働5名未達 | BPの質を総入れ替え（深さ優先の再徹底）。受託比重へシフト |
| 商品が売れない | 提案10件で受注0 | 価格でなく**対象顧客**を変える（業種を絞る）。AI取締役会で検証 |
| Familinkが伸びない | 公開6ヶ月でリテンション基準未達 | 課金を急がず市場・機能を再定義。**出口は会社売却（保険）ラインに切替** |
| 高橋の時間が再び枯渇 | 営業時間が週の50%を切る | 新規受注を意図的に止めてP8の委託を前倒し（品質毀損が最大の敵） |

## 5. 3年後に「売れる会社」である条件（出口逆算）

- 帳簿：税理士レビュー済みの月次が24ヶ月分並んでいる
- 収益：SESストック＋顧問ストックで「高橋がいなくても回る売上」が過半
- 資産：Familinkの IP・データ・プライバシー体制が整理済み（保有形態は士業確認済み）
- 関係：キャリア系・家族サービス系の買い手候補と2年の顔見知り
- **今の決算・未払い整理はこのリストの1行目**——Phase 0は出口のステップ1（CLAUDE.md）。
