# 財務モデル（統合版）

> 「検証すべき計画値」。税務の最終判断は税理士へ。金額の実数は `finance/` で空欄管理。

## お金の層
- 個人floor：プロバイド 月¥70万（高橋の労働由来）。
- 解放点：事業が月¥80万+ → ¥70万置換＋¥10万利益＝日中が空く（プロバイド事業部の"人に回す化"で達成）。
- ITS SES：1名 売上¥60万/粗利¥8万目安。ブローカー型で帳簿を作る（ITSの現金＋売却価値）。
- Familink：将来のSaaS ARR。継続率が倍率を決める。

## Phase 0の資金注意（最重要）
第2期の未払い税・社保・予定納税の可能性。8月の納税資金を最優先で確保 or 分納相談。
SESを伸ばす局面では支払（協力会社）先行・入金後行のショートにも注意。`skills/finance-cfo`。
