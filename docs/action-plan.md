## Phase 1：解放（〜+6ヶ月）— 日中を空ける

唯一の時間の作り方＝プロバイド通信事業部を「自分の手作業」から「人に回す（外注・チーム実行）」へ。
- [ ] 事業部の業務を棚卸し、自分でなくてよい作業を特定
- [ ] 外注/協力メンバーに回す（部長の立場を使う。プロバイドとの取り決め要確認）
- [ ] 指標：「プロバイド収入のうち自分の手作業由来の割合」を下げる＝日中が空く先行指標
- [ ] 目標：事業が月¥80万+を生み、損益分岐を突破

## Phase 2：加速（〜18ヶ月）— SES拡大＋Familink公開

空いた日中を使う。Claude Codeが作業を自動化するので時間は増やさない。
- [ ] ITS SESをブローカー型で拡大（理想はプロバイドへの供給/棲み分け）。`skills/ses-sales`
- [ ] Claude Codeで提案・スキルシート・KPIを自動化。`skills/ses-ops`
- [ ] Familinkをストア公開（Capacitorで既存コードを流用）。`skills/familink-launch`
- [ ] 公開後はまずリテンション（継続率）を証明 → そのうえで家族プラン課金
- [ ] 選別したAI受託を拾う（Claude Codeで作り切れる案件のみ）。`skills/ai-jutaku`

## Phase 3：出口（2〜3年目）— バイアウト

- [ ] 会社の体裁を整える（帳簿・IP所有・データ/プライバシー・KK化検討）。`docs/exit-plan.md`
- [ ] FamilinkのARR/継続率を積む
- [ ] 部長人脈経由でキャリア系・家族サービス系の買い手と非公式に接点
- [ ] 出口判断：戦略的売却（本命）／会社売却（保険）／資金調達／継続
